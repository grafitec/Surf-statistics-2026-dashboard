# 🏄 Surf Statistics Dashboard

A Power BI dashboard built from personal surf session data collected throughout 2026. The goal of this project was to transform raw activity data into meaningful insights using data modeling, DAX measures, and interactive visualizations. 

Disclaimer: This dashboard is based on personal surfing data and was created as a learning project to practice Power BI, DAX, and data visualization techniques.

## Project Overview

This dashboard analyzes surf sessions recorded over time, including:
- Surf location
- Date of session
- Time spent on the water
- Distance traveled
- Type of surf board used
- Solo or group sessions
- Night surfing activities
- Comments
- Fuel consumption and cost
- CO2 emission
- Social Media

## Key Features
- Total surfing hours, depending on surf type
- Total distance traveled, depending on surf type
- Total times i have surfed with friends and who
- Total time surfed with LED lights
- Total time social media reel got generated
- Longest distance surfed per day
- Average rides per month and week
- Most visited surf locations
- Interactive filters and slicers
- Showing distance on map per surf type
- Showing locations on map
- Showing reels from social media
- Showing most popular friends i have surfed with
- Accumulated fuel price over time
- Showing all comments from the sessions

## Technologies Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Google Sheets as data source
- Data modeling and KPI design
- Interactive dashboard design

## Example Business Questions
The dashboard can answer questions such as:
- Which surf locations are used most frequently?
- How much time is spent surfing each month?
- What is the average number of surf sessions per month?
- How does distance traveled vary between locations?
- How much money has been spent?
- How much CO2 emission has been let out in the air
